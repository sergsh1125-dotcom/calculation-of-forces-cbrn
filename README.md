
# Розрахунок сил РХБ захисту

Модуль для платформи підтримки заходів реагування на ХБРЯ інциденти.

Модуль призначений для розрахунку необхідної кількості відділень РХБ захисту
для виконання трьох основних груп завдань:

1. РХ розвідка;
2. санітарна обробка людей;
3. спеціальна обробка техніки.

## Можливості модуля

### 1. РХ розвідка

Розрахунок виконується за двома критеріями:

- розвідка маршруту — км/год;
- розвідка району — км/год.

Оператор задає:

- вид РХ розвідки;
- обсяг завдання, км;
- час на виконання завдання, год.

### 2. Санітарна обробка людей

Оператор задає:

- кількість людей, осіб;
- час на виконання завдання, год.

Можливість одного відділення задається в осіб/год.

### 3. Спеціальна обробка техніки

Передбачено три види спеціальної обробки:

- дегазація;
- дезактивація;
- дезінфекція.

Передбачено три типи техніки:

- легкові автомобілі;
- вантажні автомобілі;
- автобуси.

Оператор задає:

- вид спеціальної обробки;
- тип техніки;
- кількість техніки;
- час на виконання завдання.

Можливість одного відділення задається в одиницях техніки за годину.

## Важливий принцип розрахунку

Можливості одного відділення не є жорстко заданими у програмі.

Оператор самостійно встановлює продуктивність одного відділення
залежно від:

- типу спеціальної техніки;
- її технічного стану;
- умов виконання завдання;
- способу спеціальної обробки;
- прийнятих нормативів.

Таким чином, програма є розрахунковим інструментом, а не базою нормативів.

## Формула розрахунку

Для кожної задачі використовується формула:

    N = V / (P × T)

де:

- N — необхідна кількість відділень;
- V — обсяг завдання;
- P — можливість одного відділення за годину;
- T — заданий оператором час виконання завдання.

Результат округлюється в більшу сторону до цілого числа.

### Приклад

Необхідно провести РХ розвідку маршруту протяжністю 60 км.

Можливість одного відділення:

    20 км/год

Час виконання:

    2 години

Розрахунок:

    60 / (20 × 2) = 1,5

Необхідно:

    2 відділення РХР

## Незалежний час для кожної задачі

Час виконання задається оператором окремо для кожної задачі.

Наприклад:

- РХ розвідка — 2 години;
- санітарна обробка — 4 години;
- спеціальна обробка — 3 години.

Час однієї задачі не впливає на час іншої задачі.

## Результати

Модуль окремо визначає:

- кількість відділень РХ розвідки;
- кількість відділень санітарної обробки;
- кількість відділень спеціальної обробки.

Також формується загальна кількість відділень.

## Запуск локально

Встановити залежності:

    pip install -r requirements.txt

Запустити Streamlit:

    streamlit run app.py

Після запуску модуль буде доступний у браузері.

## Запуск через Streamlit Community Cloud

1. Створити репозиторій на GitHub.
2. Завантажити до репозиторію:
   - `app.py`
   - `requirements.txt`
   - `README.md`
3. Відкрити Streamlit Community Cloud.
4. Створити новий застосунок.
5. Вибрати відповідний GitHub-репозиторій.
6. У полі Main file вказати:

    app.py

7. Запустити застосунок.

## Використання в платформі ХБРЯ

Модуль може використовуватися як окремий розрахунковий застосунок
у складі платформи підтримки заходів реагування на ХБРЯ інциденти.

Рекомендована структура платформи:

    ПЛАТФОРМА ПІДТРИМКИ ЗАХОДІВ РЕАГУВАННЯ
    │

    ├── Розрахунки

## Увага

Значення можливостей відділень, що вводяться оператором, повинні відповідати
прийнятим нормативам, технічним характеристикам конкретної техніки та
фактичним умовам виконання завдання.

Програма виконує математичний розрахунок і не визначає нормативи
самостійно.
